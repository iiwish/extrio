## 缺陷与回归复核

复核沿任务领取、续租、取消、迟到完成/错误、终态重复领取、收集配置并发更新、Delivery 地址版本和重投预算、HTTP 跳转/压缩/重试、备份中断及恢复目标、密码重置/登录竞态追踪读写路径。发现的实质缺陷已用反例修复，详细 RED/GREEN 见 [验证记录](validation.md)。最终 498 项后端回归、173 项前端回归、构建和四桌面代表性实机 QA 通过；实际 Worker 单独重启的 Bash 空数组问题有失败测试、修复后实机验证及完整回归。

本次复核未保留已证实且未修复的 G3 范围内 P1/P2 阻断项。这是当前未提交工作树的工程复核，不是独立安全审计、全站兼容保证或生产部署验收。

## 残余边界

- 72 小时窗口仅为本机 SQLite、固定本地 HTTP 来源、三来源每五分钟调度；PG 崩溃/恢复有独立测试，没有 PG 72 小时观察，也没有外站/真实模型容量结论。
- Windows 原生运行未验证；离线互斥依赖同主机共享文件锁。外部 SQL、未知旧进程和远程多主机写入需要运维停写，不能被该锁自动证明停止。
- PG 100k 普通 cursor 可缓冲数据，实体首屏仍为约 0.9s 中位数，不宣称恒定内存或生产延迟 SLO。
- 登录型来源、未知 AccessProfile、POST、浏览器嵌套资源跳转和完整 replayable 引擎不在当前运行适配器支持范围；均应拒绝，不能展示成功。
- 既有测试默认库隔离问题已修复，但此前本地开发库的迁移执行不作回滚。保留该风险记录，不将测试全绿解释为历史副作用不存在。
- G4 尚需有鉴权完整旅程、已批准外站/模型小样本、旧版本升级/回滚矩阵、观测分析和用户签收。没有 maco、共享基础设施或生产数据库操作。
