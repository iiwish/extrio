# 数据页码分页验收

日期：2026-09-14。范围：Items 列表与可复用 ListPagination；其他列表的分页策略不在本次范围。

## 实现合同

- GET /items 可选 page 与 cursor 互斥。分页统计、实体最新观测选择、历史需求归属、过滤与排序使用现有服务端查询；LIMIT/OFFSET 读取目标页，保留游标 API 兼容性。
- pagination 提供 page/pageSize/totalPages/total。超界请求回落末页；空结果为第 1/1 页、0 行。
- 固定底栏显示行范围、总行数、每页行数、当前页/总页数、四个翻页按钮及页码跳转。每页 20/50/100/200 行，默认 50。
- URL 保存 page/pageSize；筛选或页大小变化回到首页，刷新保持页码，详情 returnTo 保留分页。列表只呈现目标页，不累积前页，换页重置列表纵向滚动。
- 未知元数据不显示伪造总数；请求失败提供目标页重试。导出传递完整筛选但不传页码或页大小，保持全集导出。
- 四份产品文档、OpenAPI、生成类型和隔离测试用 MSW 合同一致。
