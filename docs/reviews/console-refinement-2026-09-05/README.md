# 控制台体验与模型设置

状态：用户确认采用单一正式前端。本文记录诊断与阶段性验证，不代表独立体验应用的交付接受。`web/src/app` 是应用入口、鉴权与路由的唯一收敛目标；`experience.html` 的设计改动待整合，不作为第二套产品前端维护。整合必须保留真实模型配置、采集、审核、运行和数据能力，未实现的字段业务接口不能由模拟成功替代。

## 范围与设计约束

- 桌面运营控制台，以任务内容和下一步操作为中心，不增加营销区域或装饰图片。
- 导航只保留概览、采集需求、采集器、运行、数据和设置；需求上下文属于页面内容。
- 设置采用常规与模型配置两个页签。常规承载语言、示例环境和评审场景；模型配置复用正式组件、鉴权和 API，明确真实写入边界。
- 原型桌面最小宽度为 1024px，主验收为 1440x900，补充 1280x800、1132x1028 和 1024x800；正式控制台保持既有宽度范围。复杂表格在自身容器滚动，不撑大整页。
- 延续白色内容区、浅灰导航、蓝色操作、绿色成功、琥珀异常；侧栏 192px，正文 24px 边距，22px 页面标题，表格 12/13px，圆角不超过 8px。
- 空状态压缩为 240px，明确前置条件与对应跳转；审核和恢复侧栏在窄桌面收紧，不开发移动端。

## 检查结论

1. 正式模型管理组件与 GET/PUT `/api/v1/settings/models` 存在；本地 8000 健康检查通过，5173 API 代理可访问。原型设置占位与缺少 API 代理造成了功能断层。
2. 工作空间、当前需求和顶部演示控件重复占用全局导航。
3. 原型 html/body 的 1280px 硬下限造成用户 1132px 窗口横向裁切。

- 已核实真实后端中的 GLM 供应商、glm-5.3-flash 默认模型及已配置密钥状态。没有修改用户模型配置或调用付费模型。
- 模型网关与平台设置 17 项测试通过；模型设置、配置加密与角色矩阵 4 项测试通过。
- 前端定向测试 40 项通过，生产构建与阶段性体验构建通过。
- 已检查 1132px 运行/设置页面及 1024px 字段/审核页面，无整页横向溢出。截图仅是整合前的设计验证，不是正式前端验收。
- 单前端整合尚未完成。真实模型配置不等同于字段 AI 建议已接入模型。
