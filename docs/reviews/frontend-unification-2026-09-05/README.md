# 单前端统一验收

## 执行约定

用户确认只保留一套正式前端，本任务直接执行。范围为 `web` 前端入口、路由、需求列表、设置与桌面布局，以及四份产品权威文档；保留现有后端、鉴权、规则审核、运行、数据、模型与用户管理，不修改生产数据。

- 唯一入口为 `web/index.html`、`src/main.tsx`、`app/router.tsx`、`app/app-shell.tsx`，使用现有 Vite 构建与 API 客户端。
- 概览、采集需求、采集器、运行、数据、设置属于同一导航。需求列表按真实 `collectionId` 聚合采集器，创建与接入复用现有真实 API 流程。
- 设置承载语言、账号、环境、模型和已有平台管理，不提供可改写真实权限的模拟角色。
- 删除独立示例应用与专用构建；旧 `experience.html` 链接在唯一路由中兼容跳转，示例 ID 不映射为真实业务 ID。本地示例草稿不导入生产，也不删除浏览器存档。
- 延续密集运营布局；192px 侧栏、56px 顶栏，1024px 桌面下限。宽表格在自身滚动，移动端不在范围内。
- 字段模板、AI 建议和手动定义的产品方向保留；独立需求字段持久化、AI 建议 API 和字段版本发布尚无真实接口，不声称已完成，不保留模拟业务页。

## 验证计划

路由兼容、真实需求聚合、错误与搜索空状态、真实权限与已有设置回归；全量前端测试、构建、lint、单入口扫描、文档 manifest 检查；1440x900、1280x800、1132x1028、1024x800 桌面 QA。用户已有配置只读验证。

## 结果

- 统一完成：只有一个 HTML 入口、一个 React 根节点和一个 BrowserRouter。`src/experience` 的 16 个源码/测试文件、独立 HTML、Vite 配置和旧构建输出已移除；浏览器旧草稿未删除或导入真实数据。
- 全量 `pnpm test --maxWorkers=1`：25 个测试文件、98 项测试通过。覆盖旧链接映射、单入口约束、真实需求聚合/搜索/错误重试，以及已有模型保存、用户角色、审核、运行、数据和导出测试。独立示例状态机测试随对应实现移除，不计为正式业务验收。
- `pnpm build`、`pnpm lint`、`git diff --check`、文档 manifest 检查通过。
- 浏览器确认旧设置地址跳转 `/settings`；GLM / glm-5.3-flash 与密钥配置状态正常读取。需求页显示 4 个后端需求，进入对应来源筛选；新建需求与取消返回、已发布采集器详情/规则、运行和数据可访问。没有修改模型、来源、规则或执行采集，没有触发模型调用。
- 1440x900 数据、1280x800 采集器详情和英文设置、1132x1028 采集器/运行/设置、1024x800 需求列表和新建表单完成可见布局检查，业务内容无整页横向溢出。宽表格保留局部滚动。控制台无 error/warn；语言已恢复中文。
- 当前预览 5181 使用正式 Vite 配置，与标准开发端口 5173 对应同一套代码、API 和构建，不是不同前端。
