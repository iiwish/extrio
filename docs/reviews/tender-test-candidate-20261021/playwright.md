- 修改范围：浏览器适配层、探索/运行时调用、直接依赖与冻结锁、镜像安装、相关测试/验证工作流、安装文档与产品技术描述。本任务不修改 Schema、字段/原始日期/身份/指纹、签名规则、覆盖检查点或恢复预算合同。
- 使用现有稳定 Playwright/Chromium。渲染仅返回 HTML、最终 URL 与状态，不引入自主导航、模型、验证码绕过或来源重试。保留匿名 GET、robots、DNS/IP 锁定、限速/并发/请求预算、拒转发代理、上下文请求与 WebSocket 拦截；Service Worker 关闭，下载不接受。
- 保持既定 viewport、导航等待条件和异步沉降时间。只保留有界导航超时重试，网络拒绝优先，不把未知失败或限流当作成功。失败、取消和初始化异常必须关闭页面/上下文/浏览器/代理，不能遗留异步请求影响下一轮。
- 正常重新解析依赖，检查 NLTK/Crawl4AI 在锁、wheel 元数据和实际运行镜像中均不存在。不删除第三方 dist-info、不伪造版本、不排除扫描、不安装预发布包。保留历史 NLTK 研究脚本与旧回执，但不在当前无 NLTK 的镜像上执行旧预发布资格评估。
- 先增加依赖与浏览器生命周期/安全行为的失败测试，再实现；现有毒化网页/模型路径反例改为验证无该依赖及源码内容不能触发本地文件操作，不以跳过代替。
- 使用新建隔离 Python 环境和合成数据库，不同步现有服务使用的 backend/.venv。双架构原生镜像运行浏览器/PDF/EPS、网络边界、双库备份恢复、固定历史/Alpha/RC1 安装升级回归；完整主 CI、Web、wheel/sdist、完整镜像清单与 secret 扫描全部复验。
- 数据库、密钥、Cookie、真实网页/PDF/模型响应和原始采集证据全部保持受限且不提交。对现有手动实例执行只读保留清单核验；不重启、不请求发布方、不调用付费模型。
- 任一回归或扫描失败保留证据并修复；未处置 HIGH/CRITICAL 不得宣称安全通过。不合并、不发布、不推镜像、不部署、不启用来源调度；PR 保持 Draft。

4. 完整主 CI、Web lint/test/build、OpenAPI/docset、源码/打包安装；所有等级完整漏洞清单，不忽略未修复项。

## 实现与证据边界

浏览器适配层直接调用 Playwright 1.62.0，固定 1080x600 viewport、既定 UA、导航条件和沉降时长；每次 snapshot 使用无持久化上下文并在成功、失败和取消时关闭。SourceNetwork 与字段/覆盖实现保持；本地启发式编译器的新候选使用 `local-heuristic` 谱系标签，不改写历史候选、签名或 Run。

冻结锁正常移除 53 个包，包括 Crawl4AI/NLTK；没有增加包或改变保留包的版本。Playwright 与现有图像诊断使用的 Pillow 改为直接依赖。毒化样本保留，移除的第三方 API 探针由“两个包不存在 + 导入拒绝负控制 + 应用路径零导入 + 文件 canary 不变”代替，不再把 NLTK 装回运行镜像以验证旧 API。历史预发布源码研究脚本和旧回执保留，但不参与当前镜像的采用门禁。

容器 HIGH/CRITICAL 门禁包含未修复项；原生候选比较也拒绝任何残余 HIGH，不仅拒绝新增项。完整扫描保留全部等级，包清单、实际启动路径、截图/Canvas/WebGL/PDF 探针和 JUnit 与同一镜像 ID 对齐。原生矩阵同时验证历史 Debian/headless 对照，不把其残余风险当作默认 Ubuntu 候选风险接受。

精确提交的实际验证结果与 Actions artifacts 入口以[草稿 PR #49](https://github.com/iiwish/extrio/pull/49)为准；本文定义实施和验证边界，不以执行计划代替成功回执。旧默认 Ubuntu 与 NLTK 报告对应各自冻结提交，不作为本任务成功证据。所有验证均为机器辅助，不代替独立人工验收；候选不合并、不发布、不部署、不开调度。
