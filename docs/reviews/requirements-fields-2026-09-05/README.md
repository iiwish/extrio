# 需求拆分与数据字段体验验收

日期：2026-09-05。范围：独立 `experience.html` 原型，不是生产版本发布记录。

## 交付范围

- 采集需求与采集器分设一级入口，需求工作区维护业务定义与来源，采集器列表显示需求归属、活动字段/规则版本和候选状态。
- 两个字段模板预览、基于需求描述的本地模拟 AI 建议、手动添加字段进入同一个编辑器。替换与删除需确认，业务含义和示例可编辑，重名和空定义阻止确认。
- 已确认定义只读，下一版本草稿可恢复和放弃。确认版本展示新增/修改/删除，令来源候选重新验证并保留已发布版本；过期确认与旧候选不能发布。
- 样本、数据字段列、查询和导出基于字段键，不依赖固定六字段的数组位置。未知必填字段没有证据时阻止发布，未知选填字段保留空值，不使用输入示例伪造结果。
- v1 历史数据及来源规则快照独立保存，不随 v2 草稿或发布改写。原型不生成 v2 采集记录。

## 边界与风险

- AI 入口使用确定性本地公告样例，不调用真实模型；无匹配描述显示无建议。真实模型结构化输出、失败重试、消耗与权限需后续实施。
- 原型只保留一个需求与两个来源，新建动作明确确认替换本地样例，不代表多需求持久化。
- 自定义字段尚无真实来源映射；任意网站验证、数据库迁移、历史回填和生产交付未实施。
- 浏览器已执行 JSONL 下载按钮并核对确认范围；本轮未获得可读取的原生下载文件，导出结构与版本由自动测试验证，不能将此记录解读为原生下载保存已验收。
- HMR 批量改写 Context 期间出现过开发期临时错误；最终检查以稳定刷新后的界面为准。
