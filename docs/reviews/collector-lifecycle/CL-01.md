- 无生产数据操作；PostgreSQL 仅显式隔离测试库。未验证项必须列出。
- 完成标准：上述测试通过，逐条对照计划 CL-01；尚未接受的交付仅标记 Needs_Review。

## 结果

RED：首批四项生命周期 API 测试均因接口缺失失败；随后捕获不可变初始策略阻止合法空白删除、过期写入覆盖归档状态、队列重复入队三个反例。

实现：独立 lifecycle 字段、持久预览/命令、删除墓碑、管理 revision 防过期写回；009 成对迁移仅允许经过空白校验的初始化策略清理，保留其余不可变约束。调度在来源锁下重新读取，核心入队、发布、Worker 均保护归档状态。历史业务数据不删除。

GREEN：`uv run pytest tests/test_collector_lifecycle.py tests/test_store.py tests/test_worker.py tests/test_repair.py tests/test_collection_migration.py -q --tb=short`，81 passed。附加角色边界测试随后随生命周期套件验证。

符合性检查：删除与回执、审计同事务；审计失败整体回滚；实际 queued/processing 任务阻断；归档和入队竞争只有一个成功；已领取调度在归档后不能创建运行；恢复保持调度禁用；过期写入不能复活已删除来源。

剩余验证：PostgreSQL 隔离验证在 CL-04；新增响应字段的 OpenAPI 校验在 CL-03 补齐，当前旧 schema 会拒绝 lifecycle 字段，不作为最终通过项。测试中的迁移清单增加 009；AI 历史测试显式结束前一个持久任务后再创建下一个。
