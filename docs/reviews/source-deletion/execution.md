## 交付范围

删除来源保留历史身份与规则、AI 任务、操作、运行、数据、证据和投递。来源从常规列表、需求关联与统计中排除，调度关闭，URL 释放；同 URL 的新来源不继承旧身份或状态。删除不可恢复，归档仍可恢复。

删除仅受未结束的任务、运行和迁移阻断。后端在事务内复核预览摘要、阻断条件与权限，并保留幂等和审计。来源写入与投递配置变更使用来源锁，防止并发删除后继续修改旧身份；历史投递继续按原合同处理。

确认弹窗展示保留的历史数量及 URL、调度影响；阻断时不显示名称确认输入。历史运行、AI 和数据页面显示来源已删除，移除失效的来源跳转和审核、修复入口。
