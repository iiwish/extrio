# 高频来源历史追赶与询比采购

状态：一次性后台批次因核查失败停止，整批不可验收；结论及剩余工作见 `catchup-review.md`。用户明确授权中国政府采购网、南方电网、广东招标中心完成历史追赶、真实增量和广东询比采购模板。直接执行，不委派，不部署、不提交、不启动来源定时调度。当前运行与交接依据见 `catchup-background.md`。

范围：现有手动测试实例、既定 30 天首次窗口、3 天增量回看，每站每轮最多 3 个列表页、50 条；不缩小窗口或伪造检查点。扫描件、受限公告保持拒收待处理。不绕过登录、验证码、公开范围、robots 或限流。中国政府采购网的历史搜索接入沿用用户已授权的 MiMo，仍使用有界模型预算并保留真实 AI 费用与谱系；不输出密钥。既有脏工作和历史证据保留。

实施：通过受限公开 GET 固化询比采购入口、iframe、公开模板、模板声明的数据接口与渲染证据；精确模板能力及身份/阶段/日期/公开范围约束以独立签名版本审核发布。运行均通过公开 API、签名规则和真实 Worker；每个来源仅一个活动 Run，不同来源独立推进有限批次，覆盖完成后验证增量。后台监督冻结来源合同、策略及运行代码，接管已有原生操作，不并发重派同站任务。异常、锚点漂移或顺序不明必须停止派发并如实报告，不能跳过。聊天通知监督与来源定时采集调度相互独立。

允许编辑：官方文档解析器及相关固定能力的契约/发布校验、必要的分页与续跑修复、相关回归测试、四份产品规范及本评审目录。本地测试编排只保存在受限手动实例与临时脚本目录，不导入脚本结果冒充原生 Item。
