# 来源支持矩阵

状态：提案，`Needs_Review`。本文随[稳定版门槛重定义提案](releases/v1.0.0.md#稳定版剩余门槛重定义提案)提出；
批准后作为持续更新的来源支持记录，独立于软件版本，不是发布门槛。

快照日期 2026-10-31，内容整理自下列冻结证据；本次未读取业务库、未执行真实采集或模型调用。

## 使用规则

- 每个来源一行，记录状态、已签名能力、最近证据和已知缺口。状态变化须引用新的 Run 或复核记录，并注明日期。
- 目录导入、静态样本、离线模板和重复采集去重不能提升状态；fixture 不替代真实增量证明。
- 本矩阵不改变产品边界：生产 Run 只执行人工审核签名的规则，不调用模型；来源调度单独授权，目前全部关闭。
- 扩大来源实验须有有界授权计划，写明请求上限、模型预算和是否写业务库。
- 软件发行说明链接本矩阵的当前版本并列出已知缺口，不据此宣称全站兼容或真实增量覆盖。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| `受限支持` | 有经审核签名的规则和限量原生运行证据；真实增量覆盖未认证 |
| `覆盖未完成` | 有签名规则，但首次历史覆盖或真实增量存在已登记缺口 |
| `待适配` | 只有目录配置、静态样本或离线模板，没有签名生产规则 |
