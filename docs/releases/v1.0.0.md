## 范围与授权

范围沿用[单组织自托管合同](../planning/v1.0-scope-matrix.md)：本地多角色账号、
SQLite 评估、PostgreSQL 16 部署、唯一中英文桌面前端（最低 1024px）。
生产 Run 不调用模型；来源规则须人工审核发布。不新增平台功能、不重做 UI，
不扩大真实来源或模型调用预算。未批准的 P2 设计方案、移动端、PG18、生产部署、
平台级容量和月度 SLA 不属于本轮验收。

RC2 预发布授权已执行，授权范围与制品门禁见
[RC2 发行收尾](../reviews/tender-test-candidate-20261021/release-closeout.md)。
RC 风险接受不等于稳定版风险接受，预发布成功不构成历史或新增高危风险接受。
当前授权仅包括两个 P2 修复、回归测试、发行状态同步与复验。
禁止创建正式 `v1.0.0` tag 或生产部署，不启用来源调度。稳定版安全结论和验收结果仍须呈交用户，再取得相应发布授权。

## 稳定版剩余门槛

1. 当前源码的两个 P2 修复与工程验证通过，待用户复核；[本轮复验](../reviews/p2-reliability-20261022/verification.md)
   记录后端 SQLite/PG16 单次全量 1125 项通过、零跳过，前端 286 项通过，以及类型、lint、构建和真实桌面旅程结果。
   独立代码复核未发现新增 P0/P1/P2；这些结果不等于用户验收或已发布制品通过。
   候选 PR 的必需 CI 绑定其精确 head，P0/P1 不得有未处置项，P2 须有明确影响、负责人和期限。
   RC2 的 1108 项后端、278 项前端回归保留其冻结提交范围，不替代本轮结果。
2. 安全评估绑定实际候选提交与制品。2026-10-21 RC2 的完整后端清单为每架构
   0 CRITICAL / 0 HIGH / 30 MEDIUM / 16 LOW，Web 为零，包含未修复项，无告警忽略或风险豁免。
   当前冻结依赖不含 Crawl4AI/NLTK；旧 NLTK 与旧基础镜像登记属于对应历史版本，
   不作为当前制品的待接受风险。MEDIUM/LOW、未来新告警与新制品仍须完整评估，不能声明零漏洞。
3. 采购网首次历史覆盖和真实增量、发行记录中的 106 条质量待处理及六来源支持边界须明确验收。
   目录来源不等于已适配站点；扫描件、受限公告或模板不匹配不计有效正文。
   目标用户无协助操作、产品与技术最终签收均未完成，不将本交接标记为 `Accepted`。
4. 稳定版合并与发行分别获得用户授权后，main 精确 SHA 重新通过 CI 与 Container verification，
   最终双架构镜像重新完成完整扫描、签名、provenance 与发布摘要安装验证。
   PR merge SHA、RC 检查或本地镜像均不能代替。生产部署仍单独授权。

## 安装与恢复

升级和恢复步骤见 [1.0 升级手册](v0.7-upgrade.md)。记录源/目标程序和镜像摘要，
停止写入并完成全量备份；恢复只接受空目标，回退使用匹配的源程序与升级前备份，
没有数据库原地降级。已发布 RC 镜像摘要从该 Release 的 `release-verification.json`
取得，不使用 `latest`；源码稳定版本号不得充当已发布稳定镜像的安装地址。
