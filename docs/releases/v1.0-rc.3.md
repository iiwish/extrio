## 当前安全状态

2026-10-26 的[回执 PR 首轮容器 CI](https://github.com/iiwish/extrio/actions/runs/40288214343)在重建镜像中检出 4 条 HIGH：`filelock 3.32.4` 的 `CVE-2026-112940`，以及 `pypdf 6.21.1` 的 `CVE-2026-115572`、`CVE-2026-115580`、`CVE-2026-115585`。这是新建 CI 镜像的扫描，不是已发布 RC3 摘要的今日完整复扫；RC3 包含相同受影响版本，不能把 2026-10-23 的零 HIGH 快照当作当前安全放行依据。

依赖安全修复不包含在已发布 RC3 中。定向修复目标为 `filelock 4.2.1`、`pypdf 6.21.2`，范围和独立验证要求见[安全修复执行包](../reviews/dependency-security-20261026/packet.md)。源码修复与后续 PR 检查不替换 RC3 标签、镜像或三份历史回执，也不等于新的已发布候选。

上游 filelock 为 High，三个 pypdf 公告当前为 Moderate，与 Trivy HIGH 存在来源评级差异；保留差异，不据此降级或豁免。当前不以 RC3 的历史成功结果授权晋升、稳定版或部署。

## 范围与限制

- 单组织自托管、SQLite 评估与 PostgreSQL 16、唯一中英文桌面 Web 前端（最低 1024px）；不新增平台功能、API 或数据库迁移。
- [P2 修复 #50](https://github.com/iiwish/extrio/pull/50)覆盖恢复批次签名启动拒绝后的批次终结与其他批次推进、来源创建响应丢失后的幂等重试，以及全部拒绝结果的导航；不放宽签名或来源审核规则。[P2 工程回归](../reviews/p2-reliability-20261022/verification.md)保留其源码范围，RC3 的精确提交与制品验证单独列明。
- 目录工具对 1364 个入口做限量、隔离核验，包含 143 个工具异常入口复验及高校、河南交易中心、浙师大三个模板包。矩阵中的 68 个可读样本只证明限量列表/详情可读，不等于经审核签名的生产规则、完整历史、真实增量或长期支持；待适配、受限、无效输入和继承主机停止分别记录。[首轮矩阵](../reviews/catalog-validation-20261023/verification.md)与[复验及模板证据](../reviews/catalog-followup-20261023/verification.md)不作为整站兼容性承诺。
- 采购网首次历史覆盖和真实增量仍未完成；冻结六来源发行记录中的 106 条质量待处理不计有效正文。目录清单、静态样本和离线模板不扩大六来源已有支持边界。
- 保持零付费模型、不写现有业务库、不启用来源调度，不进行真实采集。既有实例未升级；本轮不部署、不迁移或重启既有实例。仅使用独占临时资源和合成账号验证安装。
- 72 小时观测沿用已有豁免，不计为通过；RC 风险接受不等于稳定版风险接受，不新增安全风险豁免。

## 安全清单与回执

实际发布制品的完整扫描包含未修复项：backend 每架构 **0 CRITICAL / 0 HIGH / 30 MEDIUM / 16 LOW**，Web 两架构均为零，UNKNOWN 为零。HIGH/CRITICAL 维持全部阻断；MEDIUM/LOW 保留完整清单和评估，无忽略告警、风险豁免或零漏洞声明。这是 RC3 实际摘要的结果，不因计数与 RC2 相同而借用旧结论，也不代表未来漏洞库或稳定版结果。

`CVE-2026-88648`（`libgnutls30t64`）在 Ubuntu 制品扫描中为 MEDIUM，原始报告同时保留 Red Hat CVSS v3 **7.4**。[Ubuntu 官方记录](https://ubuntu.com/security/CVE-2026-88648)为 Medium、CVSS v3 **3.7**，Noble 状态为 `Vulnerable, fix deferred`。保留厂商与来源分数差异，不标记为不受影响、误报或已修复；攻击前提涉及攻击者控制从属 CA 并利用证书名称约束校验。它低于未改变的扫描器 HIGH/CRITICAL 阻断线，不构成安全风险豁免。后续候选继续跟踪 Ubuntu 状态并重新扫描。

## 安装与稳定版

升级、空目标恢复和匹配源程序回滚遵守 [升级手册](v0.7-upgrade.md)，没有数据库原地降级。安装只使用实际发布且通过签名/provenance 核验的摘要，不使用 `latest`、CI 本地 image ID 或包版本推导的地址。隔离安装不是生产部署，不自动导入开发实例的来源规则、数据或凭据。

正式稳定版的来源覆盖、质量待处理、目标用户旅程、候选安全评估及产品/技术签收仍按 [稳定版交接](v1.0.0.md)单独验收。任何 RC3 成功结果仅适用于其精确提交和制品，不授权稳定版或生产部署。
