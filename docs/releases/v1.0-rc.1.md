## 范围

单组织自托管；本地管理员、工程师、审核人和只读角色；SQLite 评估、
PostgreSQL 16 部署；唯一桌面 Web 前端，中英文，最低 1024px。
模型只用于编译与修复，生产 Run 不调用模型，真实来源规则必须人工审核发布。
多租户、SSO/MFA、高可用、移动端及尚未批准的 P2 体验方案不在本次范围。

## 本地门槛

验证结果与命令见[收尾证据](../reviews/v1.0-closeout-2026-09-26/verification.md)，
缺陷复核见[审查记录](../reviews/v1.0-closeout-2026-09-26/review.md)。
升级与恢复回退见[操作步骤](v0.7-upgrade.md)。保留旧程序与升级前完整备份，
禁止把旧程序直接连接到已升级数据库。

本机镜像是 Linux ARM64 试验制品，不作为远程 AMD64 或签名证据。测试用
HTTP cookie、匿名本地来源和自动迁移仅在隔离测试环境显式开启，生产默认值
仍要求显式迁移、HTTPS、安全 cookie、关闭匿名 HTTP、关闭 demo 与公开 metrics。

## 稳定版边界

稳定 `v1.0.0` 需要独立的版本元数据、RC 到稳定版升级/恢复、已发布镜像的
digest-pinned 安装证据及稳定版精确提交的发布检查。NLTK 告警的 RC 风险接受
仅适用于本 RC，不延伸至稳定版。稳定版发布及生产部署分别需要用户授权，
当前收尾授权仅覆盖修改、测试、提交、推送和创建 PR。

## 已知边界

- 真实 DeepSeek 验收为一个公开来源、三个详情样本；不支持外推站点成功率。
- 模型任务中的两次输出截断由原有有界恢复处理，模型用量证据保留失败调用；
  总量 58,891 token，不推算金额。没有发布该来源候选。
- 72 小时观测由用户豁免，不声明长期稳定性、月度 SLA 或平台级容量达标。
- PostgreSQL 18 与托管生产环境不在已验证范围。远程双架构 RC 制品已通过上述发布门槛；
  已发布摘要的实际安装验证与本地重建验证分开记账，见稳定版交接。
- NLTK 间接依赖存在尚无修复版本的 HIGH 告警 `GHSA-8mgp-746c-j5xp`；
  [静态初审](../reviews/v1.0-closeout-2026-09-26/review.md)未发现受影响模型文件 API 的调用，
  告警保持 open，RC 风险接受不构成已修复或全应用不可达证明。
  稳定版须单独审阅残余风险。可修复高危为零不等于全部漏洞为零。
- 聊天中提供的供应商密钥只用于本次输入，不进入仓库、报告或用户实例；
  正式部署应使用单独、可轮换的凭据。
