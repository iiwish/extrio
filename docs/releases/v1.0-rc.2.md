# Extrio 1.0 RC2 测试候选版

状态：用户暂缓发布，继续安全处置，`v1.0.0-rc.2` 尚未发布。Python 包版本为 `1.0.0rc2`，Web 包版本为 `1.0.0-rc.2`，数据库目标为 schema 014。该版本不是正式商用版，不表示最终产品/技术签收。

## 范围

单组织自托管，SQLite 评估与 PostgreSQL 16，唯一中英文桌面 Web 前端，最低 1024px。六个代表来源支持经审核签名的规则、列表与详情字段证据、公开原文跳转、文本层 PDF、限定公开 EPS 模板、覆盖进度和质量交付分离，以及有次数/期限/请求硬上限的有限冷却恢复。采集运行不调用模型。

## 已知限制

- 中国政府采购网中央单位采购公告的首次窗口自 2026-09-19 起，续跑保留在第 99 页；后续响应持续限流，首次覆盖和真实增量未完成。三次有界恢复均失败并终止，不自动重试。按日期分段仍是待验证方案。
- 本地六来源验证实例有 4751 个有效去重实体、106 条质量待处理。复旦 2 条扫描 PDF；广东 80 条可见范围待审核、21 条模板不匹配、2 条缺少详情框架和 1 条连接失败。待处理不计有效正文，不产生有效版本或交付。
- 导入的 1480 个来源是目录配置，不是 1480 个已适配站点。OCR、图片规格、通用附件及长期稳定性不在完成证明内。
- 全部来源调度保持关闭。本次发布不部署生产，不分发真实数据库、密钥或原始采集证据；安装后需单独配置实例和来源，不自带用户测试数据。

## 发行门槛

候选提交须通过完整双库/前端回归、依赖和源码安全扫描、双库升级/恢复与隔离安装、精确提交 CI 和 Container verification。默认浏览器使用稳定 Playwright，冻结依赖不含 Crawl4AI/NLTK。完整扫描包含未修复项，任何 HIGH/CRITICAL 均阻断候选；既有 main 祖先校验、签名及 provenance 保持，未处置风险不自动豁免。

执行范围、授权和本地证据位置见[执行契约](../reviews/tender-test-candidate-20261021/packet.md)。正式稳定版的独立门槛见[v1.0.0 交接](v1.0.0.md)。旧版本回滚须使用升级前完整备份和匹配源程序，不允许数据库原地降级。
