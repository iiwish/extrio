# 详情页逐页打磨

| --- | --- | --- | --- |

| 3 | 采集运行详情 `/runs/:runId` | 本次结果、终止原因、范围完整性、执行过程、拒绝数据与恢复入口 | 首轮实现，待用户验收 |

## 模型设置合同

- 默认模型与添加供应商保持单一工具栏；供应商使用共享 DetailPanel 白色 8px 卡片，间距 16px，模型为内部平铺行，不嵌套卡片。
- 供应商身份与操作在首行，凭据状态、启用状态和数量在次行；名称 14px/22px、正文 13px/20px、辅助 12px/18px。沿用蓝色操作、绿色就绪及琥珀色警告；不增加图片或动画。
- 模型默认展开，保留轻量折叠；长 URL 和模型 ID 支持换行。编辑弹窗统一宽度、边距及内部滚动。
- 保留默认模型保存、启停、删除确认和密钥隐藏。保存失败在操作弹窗中展示，不添加模拟连通性测试。

## 系统设置合同

- 偏好与账户、实例运行状态、采集策略、用户管理使用统一白色 8px 边界面板，间距 16px；复用 DetailPanel，避免嵌套卡片和装饰性分隔线。
- 运行指标并列展示，Worker 标识支持换行；用户表保持稳定列宽，狭窄桌面仅表格内部横向滚动。
- 保留管理员权限、当前用户与最后管理员保护、密码重置流程和真实状态刷新；视觉验收不修改账户或安全策略。模型分区单独打磨。

## 需求明细设计合同

- Standard 级运营页面优化；目标是快速看清“采集什么、字段是否发布、哪些来源未对齐”，不设计营销首屏或新增后端能力。
- 首屏名称先于状态标签；目标紧随名称，发布覆盖和生效版本组成紧凑事实区。来源规则已发布与字段目标已对齐明确分开。
- 字段和关联来源仍为两个 URL 分区；字段工具归并模板、AI 建议与来源导入，保留编辑/发布主操作和历史入口，不重复显示生效版本。
- 白色表格、浅灰表头、8px 工具边界；正文 13px/20px、名称 22px/30px、辅助信息 12px/18px，字距 0。沿用现有字体和颜色变量；正文 #20282d、辅助 #59676f、边线 #e1e6e9、行动蓝 #1d49bd、对齐绿 #267263、风险色 #846013。
- 来源表使用明确的五列宽度，URL 可换行，操作不被挤出；不以卡片嵌套和大量线条分隔业务信息。详情保持文档滚动，长表仅内部横滚。
- 有目的的交互：工具菜单支持键盘及关闭后焦点恢复；对齐入口切换来源并聚焦分区；长目标展开/收起保留完整内容。无新增动画或装饰图片，使用现有 Lucide 图标。
- 保留权限、revision 冲突、发布确认、迁移确认、归档行为、未保存草稿和离开保护；不自动发布、采集或迁移。不统一重写其他详情页，待第二个页面成熟后再决定共享抽象。
- 自动测试覆盖字段工具菜单、焦点、只读/编辑状态、来源列与现有 CRUD/发布保护；构建、lint 与四种桌面尺寸验收。浏览器使用真实本地数据只读验证，写操作由隔离测试覆盖。

## 走查发现

1. 首屏状态先于名称，生效版本在页头和字段区重复出现；目标与状态间被多道线条拆散。
2. 字段工具有六个并列按钮，模板与 AI 建议等低频操作挤占编辑/发布的视觉优先级。
3. 关联来源表沿用三列的 65%/20%/15% 宽度，但实际有五列，字段数与管理入口被挤出可见区。

截图与验收记录存放于 `docs/reviews/collection-detail-polish/`。

## 新建来源合同

- 使用来源列表上的最大 960px 宽弹窗，顶部标题固定、表单内部滚动、底部操作吸底。统一 8px 圆角及 14px 面板标题，URL 输入占满可用宽度。
- 归属需求、批量 URL、文件导入、逐行校验沿用现有流程；CSV/TXT 格式说明按需展开。单条成功进入来源详情，批量结果保留独立结果页。
- 遮罩不关闭，关闭与取消经过既有未保存保护，提交中禁止取消和关闭。保留部分成功反馈，不自动发布或采集。

## 新建需求合同

- 两项必填输入保持需求名称与采集目标，在需求列表上使用最大宽度 640px 的创建弹窗，内边距 24px，标题 18px/26px，输入正文 14px。遮罩点击不关闭，提交期间阻止关闭，取消回到列表。
- 操作栏区分取消与创建需求；提交中显示加载图标并锁定操作。创建按钮名称不影响编辑弹窗的保存需求操作。
- 保留空白校验、长度上限、角色限制、错误恢复和幂等提交。真实浏览器只读验收，不创建测试需求。

## 数据明细合同

- 复用 DetailPanel、运行详情页头与 Tab 样式。四个分区保留内容、版本、质量、来源追溯；来源正文仍为转义的纯文本或 HTML 源码，不执行采集内容。
- 正文优先阅读，元信息使用无分隔线的紧凑事实区。正文 14px/26px，面板标题 14px/22px，辅助信息 12px/18px；白底、8px 圆角、16px 面板间距。
- 长标题完整换行，来源追溯使用无嵌套卡片的信息行，URL 与版本差异可换行；保留拒绝原因、缺失状态、观察历史和技术标识。
- 验证四种桌面尺寸、正文/HTML 切换、分区深链接与自动测试。仅只读浏览，不访问外部来源或修改数据。

## AI 任务详情合同

- 与采集运行复用 DetailPanel 及页头、Tab、统计样式，四个分区保持结果、执行过程、模型调用、证据。标题 22px/30px，面板标题 14px/22px，正文 13px/20px，辅助信息 12px/18px；8px 圆角、16px 面板间距、无阴影。
- 产出与审核入口优先，调用量及验证结果集中呈现。执行过程按阶段展示，模型调用保持可扫描列，长模型名换行；证据与技术标识分层，不展示敏感提示词或响应正文。
- 保留深链接、轮询、失败与删除来源历史语义；只读验证真实记录，不触发 AI 生成或审核发布。四种桌面尺寸与自动测试验证，无移动端或生图范围。

## 采集运行详情合同

- Standard 级桌面工作台优化。结果、执行过程、范围与增量、质量与证据保持四个 URL 分区，保留取消权限、异常诊断、历史归属和证据真实性。
- 与来源详情共享 DetailPanel 工作面板：白底、#e1e6e9 边框、8px 圆角、无阴影；面板间距 16px，标题 14px/22px，正文 13px/20px，辅助信息 12px/18px。页头 22px/30px，Tab 透明背景。
- 执行过程突出阶段进度与实际计数，去掉指标网格和阶段行的密集边线；质量证据使用无嵌套卡片的信息网格，技术详情按需展开。
- 保留键盘 Tab 导航、结果筛选及焦点定位，不新增真实运行、模拟数据或图片。四种受支持桌面尺寸检查长 URL、标题、指标及按钮，运行前端测试/build/lint。

## 来源详情首轮合同

- 保留 URL 优先的三个分区和全部现有业务操作。配置、运行结果、规则证据统一使用白色、浅边框、8px 圆角的工作面板，分区间距 16px。入口配置内用浅灰 URL 条突出地址，说明与需求归属在其下方展示。规则工作区直接展示，不提供折叠入口。
- 定时运行与采集范围以两列对比，状态和实际配置值优先；标题 14px/22px、正文 13px/21px、辅助信息 12px/18px，沿用需求明细的中性配色和 8px 工具边界。页头 22px/30px，动作保持可换行，长 URL 完整可读。
- 数据合同与投递保持按需展开。规则审核、运行结果、修改确认、调度开关与写操作不改变。只调整详情命名空间的样式，不影响已验收列表。
- 需求提示使用“尚未应用最新字段要求”，说明来源不会自动更新；未知版本不以已对齐代替，导航只查看来源，不执行迁移。
- 验证四种桌面尺寸、URL 编辑弹窗与取消、规则/结果分区，以及全量前端测试/build/lint；本轮不运行真实采集或改变用户配置。
