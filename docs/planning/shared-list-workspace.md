# 通用列表工作区

状态：实现与技术验收完成，待用户体验复核。用户授权统一需求、来源、运行和数据列表的视觉与滚动体验；本任务直接执行，不委派，不修改后端或真实数据。

## LW-01

- 范围：共享 ListWorkspace 组件及测试、四个列表页面及相关测试、共用中英文文案、作用域样式、四份产品文档与验收记录。
- 组件负责固定工具栏、数量状态、通知区、剩余高度、独立滚动区域与可选分页 footer；业务查询、筛选、行渲染、权限、导航和导出留在页面。
- 高度通过 100dvh 和 flex/grid 剩余空间自动计算，不写死各页高度，不引入 window resize 监听或重复测量。筛选换行、运行视图 Tab 与错误提示自动参与高度分配。只有列表内容滚动，表头吸顶，宽列在同一区域横滚。
- 数量区分已显示/已加载与服务端总数；加载或读取失败不宣称零条，刷新失败保留已有数据且提示过期。分页不重置已读位置，筛选变化重置滚动位置。
- 视觉：Standard 级运营界面；固定顶部工具栏、白色单一列表工具面、8px 圆角，无卡片嵌套；行约 68-80px、标题14px、次级12px；需求说明最多一行、完整内容保留 title 和详情；中性灰背景，蓝色动作、绿/橙/红只表达真实状态。
- 不改变详情页滚动，不增加移动端范围，不新增依赖或模拟数据。
