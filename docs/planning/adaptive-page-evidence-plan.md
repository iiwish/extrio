# 自适应网页证据读取实施计划

状态：Needs_Review。实现、受控回归与桌面证据已提交评审。AE-05 多轮效率优化的独立真实验证使用 glm-5.3-flash，在 16 次上限内实际调用 5 次，三个详情样本验证通过；未发布、未覆盖现有采集器。单来源结果不代表全部网页或模型兼容性。

## 目标与范围

规则生成和修复使用“结构索引、按需读取、确定性验证”的有界多轮协议。模型可以选择读取已抓取页面的哪些区域，但不能决定任意网络访问、执行脚本或修改输出合同。生产运行仍执行已发布规则，不调用模型。

网页表示采用 HTML DOM 结构索引，不构造 JavaScript AST。保留列表与详情阶段、样本身份、节点路径和元数据，避免丢失选择器上下文。大窗口模型减少轮次，小窗口模型通过多轮取得必要证据；不保证任意小窗口或任意复杂网页均能完成。

不在范围：新增模型供应商原生 SDK、任意浏览器 Agent、自动发布、修改现有规则/生产数据、绕过来源安全策略、无限重试、完整文档语义理解与移动端布局。

## 当前集成点

- `model_gateway.py` 使用 OpenAI-compatible chat/completions，生成与修复通过 `adaptive_compile.py` 共享预留、按需证据和有界提案协议。
- `explorer.py` 保存列表和最多三个详情完整样本，对所有样本执行字段、标题、URL 与身份验证，失败反馈可继续补读。
- 模型配置支持可选 limits，API、OpenAPI、生成类型、设置页与旧配置兼容；需求字段建议保持其独立的既有调用限制。
- 模型调用记录保存 usage 与响应 digest；证据诊断仅保留节点、范围、快照摘要、预算与稳定诊断，不保存原始提示词或网页正文。

## 技术方案

### DOM 索引与只读读取

每个不可变页面快照建立独立索引，节点 ID 仅在该快照内有效。索引包含 tag、精简属性、子节点数量、文本长度、链接密度、少量预览及 pageId/stage。索引自身分页，并允许展开被折叠的子树，不能先截断目录再声称覆盖整页。

正文、列表记录和表格作为结构块。超大节点继续分页；表格块保留表头和行范围。返回值带祖先路径、快照 digest、片段范围、是否完整以及下一页游标。编号不是网页可注入或自行指定的执行权限。

模型通过受约束 JSON action 请求 `expand_nodes`、`read_nodes` 或 `propose_rule`，不依赖供应商原生 tool calling。读取只解析已加载快照中的白名单节点与合法游标，不支持文件路径、任意 URL、JavaScript、XPath 或 shell。

### 有界多轮控制器

每轮发送固定任务合同、紧凑结构索引、当前选中证据及验证反馈；不无限追加原始聊天记录。应用维护读取覆盖与候选状态，不依赖模型自由文本摘要作为唯一记忆。

先定位区域，再读取证据，最后提交现有 RulePlan 格式。小页面可以首次响应直接提交规则。无效 action、越界读取、重复读取及无进展轮次均计入预算。生成和修复共享控制器，修复仍冻结原合同。

首次候选执行完整快照验证。字段缺失、标题不一致、URL 交接或标识冲突反馈为结构化诊断，允许在剩余预算内补读和重新提案。失败不自动接受风险或排除字段。预算耗尽返回明确错误，保留原候选及读取诊断。

### 模型能力与预算

模型配置增加可选的上下文、最大输入、最大输出及推理预留参数；旧配置可读写，默认使用标明为估算的保守能力配置。配置绑定实际供应商、模型和接口，不能仅凭模型名称猜测代理平台上限。

适配器分别处理总上下文与独立输入/输出约束。每次请求预算包括消息封装、提示词、合同、结构索引、证据、反馈和输出/推理预留。优先用匹配模型的本地 tokenizer；未知模型使用保守估算、额外余量和可见的估算标识，不宣称精确计数。供应商拒绝上下文长度时有界缩减后重试，不静默截掉请求。

新任务上限：总模型调用 16 次（包含发现、提案与重试）、总预留输入 token 120000、总预留输出 token 16000、总时间 240 秒，每轮最多读取 6 个节点。发现最多消耗 12 次，为编译与校验保留 4 次；历史恢复不提高原调用上限。按实际上下文余量分配每节点最多 6000 字符，展开最多 16 个子节点。连续三次无新证据或新提案停止。每次发请求前预留预算，缺少 usage 时也不能免费重试。实际 usage 用于校准和诊断；未配置价格时只展示 token，不伪造费用。

合同和最小响应空间已超出模型能力时，在调用前报能力不足。取消、超时、Worker 租约失效终止后续调用，不能提交失去任务所有权的结果。

### 可观察性

AI 任务展示读取阶段、调用次数、预算使用、是否覆盖所需证据和停止原因；区分网页下载不完整、模型证据局部读取、字段验证失败与上下文不足。覆盖率按已索引/已读取节点或字节描述，不声称语义识别准确率。

诊断只记录节点 ID、范围、快照摘要、预算和稳定错误码。完整网页仍遵守既有 Artifact 保存和访问权限，不向普通日志复制正文、凭据或供应商原始响应。

## 验收矩阵

- 8K、16K、32K、128K 是测试预算档位，不是对任何型号能力的断言。固定任务能适配时完成；无法容纳合同的档位必须明确拒绝，不能超限发送或伪报成功。
- 同一组长网页在可支持档位下输出一致的字段语义、具体明细 URL 和独立实体标识；低窗口可以多轮，但不能降低质量门。
- 覆盖正文位于页尾、多块正文、重复导航、嵌套表格、超长单节点、混合中英文、多个详情模板、恶意页面提示词、JSON 列表兼容。
- 实际发送的每轮请求均符合该模型预算；统计整个任务而不是仅统计最后一次调用。
- 不把节点切片当作完整正文输出；生产提取始终使用完整抓取结果。
- 取消及预算耗尽保留可诊断结果，不发布、不写入生产 Item、不覆盖可用规则。
- `backend/.venv/bin/pytest backend/tests -q`；PostgreSQL 在明确隔离的测试实例验证，不修改占用默认端口的其他数据库。
- `pnpm --dir web test`、`pnpm --dir web build`、现有 lint/type/合同及文档 manifest 检查。
- 桌面 QA：1440x900、1280x800、1132x1028、1024x800；不引入移动端范围。
- 固定快照和可控模型模拟器是主要回归证据；真实供应商验证注明具体配置、调用次数和费用限制，未实测模型不宣称兼容。

## 确认边界

AE-05 的一次真实验证授权已使用，实际 5 次调用且未发布。后续真实模型复验需单独确认，不以失败为由追加调用或放宽预算。预算、模型配置和界面改动按上述边界交付；工程证据、真实模型效果和用户验收分别记录。
