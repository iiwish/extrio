## 产品合同

删除来源是不可恢复的来源生命周期操作，不是历史数据清理。来源退出列表、需求关联与来源统计，调度关闭，URL 释放；相同 URL 可创建独立的新来源，不继承规则、检查点、策略和任务。归档可恢复，归档来源继续占用 URL。

规则、AI 任务、操作、运行、数据、证据、投递及历史所属需求保留原始引用。历史页面标记“来源已删除”，不提供跳转到已删除来源或继续审核、修复、执行的入口。已有历史投递按原投递合同处理，不隐式重发或取消。

仅实际排队/执行中的任务、未结束运行及未完成迁移阻止删除。确认页列出保留的历史数量、关闭调度和释放 URL 的影响；阻断时不显示名称确认输入。提交时重新检查阻断条件和预览摘要，权限、事务、幂等和审计保持有效。
