## 来源边界

收录采购单位/集团自建采购系统、学校及科研院所、医院、政府采购公告发布渠道、官方交易场所和可识别的采购代理机构首发栏目。

不收录千里马、采招网、剑鱼、采购与招标信息聚合类服务等商业二手集合站。未能明确区分“自办项目发布”和“信息聚合”的通用第三方平台，也不作为可用一手源交付。代理机构栏目只适用于其自己受托办理的项目，不是该站所有信息均可认定首发。

**平台归属官方，不等于每条公告都是一手。** 政府采购和公共资源交易网站可能同时直接发布、依法公开或同步其他平台的信息。`sourceRole` 明确标注这一边界；生产采集必须按公告的采购人、代理机构、发布单位和原文链接逐条溯源，排除纯转载。全国公共资源交易平台、招标投标公共服务平台的全国汇总入口只用作发现官方来源，不混入可用主表。

目录发现范围涉及中国内地31个省、自治区、直辖市及新疆生产建设兵团，并补充高校、医院、企业和金融机构官网。**不代表这些地区的可用列表全部覆盖**；港澳台不在本轮系统整理范围。未确认的地域标记为“未标注”，不根据企业注册地或校名随意推断项目覆盖地区。

## 核验口径

主表的普通HTTP记录须同时满足：请求成功、无访问阻断/登录墙、至少识别3个不同的公告链接、至少2个公告链接附近有最近120天内且不晚于核验日的完整日期，且最近30天内能观察到更新。30天内未见更新的列表移入待复核表，不将低频发布直接认定为停更。日期取自公告链接附近的小范围文本，排除仅凭页面页脚、首页新闻日期或HTTP 200判断可用。少数重点栏目另有官方网页工具的可读列表证据，并与本机HTTP结果分开标注。

`latestObservedDate` 是页面公告附近观察到的最大日期，不等于已逐条核对的法定发布时间。`recentItemCount` 是当前页可识别的近期日期样本数或网页复核的保守下界，不是全站公告量、日增量或采集覆盖率。页面模板存在差异，接入前仍需人工检查栏目和日期的对应关系。

核验使用匿名只读请求，没有注册、登录、验证码识别、代理轮换、突破风控或访问未公开接口。对未发出的本机连接池超时进行隔离批次核验；没有反复重试源站拒绝访问的页面。TLS或连接超时只表示当前客户端未通过，不能证明站点永久失效。

**这是一天内的可读性和更新线索核验，不是长期稳定性承诺。** 没有逐站完整翻页、连续多日监测、全部详情解析、附件下载、robots核对或商业使用条款审查。`paginationEvidence` 仅表示是否看见翻页入口，不表示已验证完整枚举。

## 登录标记

- `loginRequired=否`：本轮匿名请求或官方网页复核能看到公开列表。只描述列表查询。
- `loginRequired=是`：观察到登录表单或明确“登录后查看”提示，且没有可见公开列表。此类记录在待复核表，不以单纯出现“登录”按钮推断。
- `loginRequired=待核验`：JS外壳、网络错误、验证码/风控、HTTP拒绝等无法确认的情况。403、412、429不能直接标记为需要账号。
- `detailLoginRequired`、`attachmentLoginRequired`、`businessLoginRequired` 分别描述正文、附件及报名/投标业务。未实际核对的统一标为“未核验”，不从列表免登录推断。

`sampleDetailUrl` 只是从列表观察到的详情链接，可用于后续适配测试；不表示该详情已打开或免登录。不提供账号或CA证书，也不使用这些资源规避公开查询限制。

## 接入使用

先从主表选择 `verificationStatus` 为普通匿名HTTP可读的栏目做解析、编码、去重和翻页测试。网页复核但本机HTTP失败的条目，先完成网络及页面传输适配。待复核表只用于排期，不直接启用调度。

主表前四列保持项目既有导入字段：`entryUrl,mode,name,scopeHint`。主表可直接作为来源配置输入；导入前自行挑选目标批次，不把“导入成功”当成抓取规则或商用许可已就绪。待复核表超过导入行数上限时必须先筛选，站点目录表不支持直接作为公告列表导入。

接入时应记录原始公告URL、来源平台、采购人/代理机构、项目编号、标段、公告类型、发布时间、截止时间、预算/中标金额和附件元数据。跨站去重优先结合项目编号、采购人、标段和公告类型，不能只按标题去重；更正、终止和结果要与原项目关联，不能当重复项丢掉。采购意向、招标计划、中标候选人和最终中标结果应分类型保存。

公开可读与批量采集、全文再分发、附件再托管、商用许可是不同问题。生产接入前逐站核对服务条款、robots和授权边界；涉及联系人、电话及其他个人信息时单独评估展示与存储范围。限制访问时停止自动请求，改为人工确认或申请接口/授权，不绕过登录、验证码、付费或CA边界。

建议用有界的同站低频请求、缓存、条件请求、退避和断路器做上线验收；对样本栏目开展多日定时复查，记录可达率、首条公告变化、分页是否完整以及源站改版情况后，再认定为长期稳定源。该多日复查不在本次已执行范围内。
