# Support

Extrio is self-hosted software in its 1.0 release-candidate phase, maintained on a best-effort
basis.

- Use [GitHub Discussions](https://github.com/iiwish/extrio/discussions) for setup questions and
  design discussion.
- Use [GitHub Issues](https://github.com/iiwish/extrio/issues) for reproducible bugs and scoped
  feature proposals.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the Extrio version or commit, deployment method, operating system and architecture,
reproduction steps, expected behavior, logs with secrets removed, and relevant request IDs.

Prereleases have no response-time or compatibility SLA. Maintainers prioritize security,
data-integrity, and release-blocking defects before feature requests.
